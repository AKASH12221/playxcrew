# PlayXcrew 🎮

**PlayXcrew** is a live esports tournament platform where players discover upcoming tournaments, team up in squads, book their slots and compete.

🌐 **Live site: https://playxcrew.com**

## What the platform does

- **Player accounts** — sign up, log in and manage a player profile
- **Squads** — create a squad, invite teammates and manage your lineup
- **Tournament booking** — browse scheduled tournaments and book a slot for your squad
- **UPI payments** — pay for bookings through UPI with a guided, step-by-step payment flow
- **Membership passes** — passes that let regular players book member-only tournaments and play every week

## Tech stack

- **Frontend:** HTML, CSS, JavaScript — deployed on **Vercel**
- **Backend:** Node.js with Express — hosted on **AWS EC2**
- **Database:** SQLite
- **Payments:** UPI-based payment flow
